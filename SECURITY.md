# Security Policy

## Supported Versions

Only the latest commit on the `main` branch receives security fixes.

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub's
[private vulnerability reporting](../../security/advisories/new)
(Security tab → "Report a vulnerability"). Include steps to reproduce and the
affected files or versions. Never include real secrets or personal data in a report.

You can expect an initial response within 7 days. Confirmed issues are fixed on a
best-effort basis and disclosed after a fix is available.

## Scope

This is a personal open-source project provided as is. Never commit `.env` files,
private keys, or other credentials to the repository.
